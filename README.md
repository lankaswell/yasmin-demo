# Yasmin — demo del sito

Demo statica del sito della Dott.ssa Yasmin Khreiwesh, conforme alla direzione visiva approvata. File pubblicati: esclusivamente `site/`. Brand book e riferimenti non sono inclusi nel repository pubblico.

Per vedere la demo localmente: `python -m http.server 8000 --directory site`.

Le otto pagine vengono generate da `build_demo.py`. Dopo aver modificato testi o navigazione nel template, eseguire `python build_demo.py`. Lo stile conserva palette, firma Allura e impaginazione editoriale del brand book Yasmin v4; Manrope resta il sostituto temporaneo di Nourd. La homepage include un accesso diretto alle attività. Menu e sottomenu supportano tastiera, Escape e cambio tra schermi piccoli e grandi.

Il modulo dimostrativo non invia né salva dati. Curriculum, sedi, testimonianze e materiali artistici devono essere forniti e approvati prima della versione definitiva. Le fotografie sono illustrative.

Tipografia: Allura e Manrope (alternativa temporanea a Nourd, in attesa della licenza web). Font ospitati localmente; nessun analytics, cookie o servizio esterno caricato dal sito. La demo chiede ai motori di ricerca di non indicizzarla.
